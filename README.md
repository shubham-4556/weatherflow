# 🌦️ Climate

> A modern, responsive weather application built with **React**, **TypeScript**, **TanStack Query**, **Shadcn UI**, **Tailwind CSS**, and **Recharts**. Designed with clean architecture, real-time weather data, interactive visualizations, and a seamless user experience.

---

## 📖 Overview

Climate is a modern weather application that provides accurate, real-time weather information with an intuitive and responsive interface. Built using modern frontend technologies and best practices, the project demonstrates scalable architecture, efficient state management, and performant data fetching.

Whether you're checking the current weather, exploring hourly forecasts, or analyzing weather trends through interactive charts, Climate delivers a smooth and engaging experience across all devices.

---

## ✨ Features

- 🌍 Search weather by city
- 📍 Detect current location
- 🌤️ Real-time weather conditions
- 🌡️ Hourly weather forecast
- 📅 7-Day weather forecast
- 📊 Interactive weather charts
- 🌅 Sunrise & Sunset information
- 💨 Wind speed and direction
- 💧 Humidity levels
- 🌧️ Precipitation details
- 🎨 Beautiful modern UI
- 🌙 Dark / Light mode
- 📱 Fully responsive design
- ⚡ Fast data fetching & caching

- 🚀 Optimized performance

# 🚀 Getting Started

## Clone the repository

```bash
git clone https://github.com/your-username/climate.git
```

## Navigate into the project

```bash
cd climate
```

## Install dependencies

```bash
npm install
```

## Start development server

```bash
npm run dev
```

The application will be available at

```
http://localhost:5173
```

---

# 📦 Build for Production

```bash
npm run build
```

Preview the production build

```bash
npm run preview
```

---

# ⚙️ Environment Variables

Create a `.env` file in the project root.

```env
VITE_WEATHER_API_KEY=your_api_key
VITE_BASE_URL=your_api_url
```
